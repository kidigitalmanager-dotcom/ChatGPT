# Statements Demo

Die klickbare HTML-Demo liegt direkt in dieser Datei:

**[Statements Demo.html öffnen](Statements%20Demo.html)**

Zum Herunterladen die Datei öffnen und rechts oben über dem Quelltext auf **Download raw file** (Pfeil nach unten) klicken. Anschließend die gespeicherte `Statements Demo.html` per Doppelklick im Browser öffnen. Eine Installation oder Internetverbindung ist dafür nicht erforderlich.

Die Demo enthält 61 Monate von Oktober 2021 bis Oktober 2026. Der Bruttoumsatz beginnt bei **10.000 $ pro Monat**, steigt auf **420.000 $ pro Monat** und ergibt insgesamt genau **3.642.057 $**. Davon stammen **742.057 $ aus Abos** und **2.900.000 $ aus Chatting / PPV Messages**. Alle anderen Umsatzkategorien stehen auf 0 $. Das Ranking oben links zeigt **Top 0,1 % der Creator**. Nettowerte berücksichtigen eine angenommene Plattformgebühr von 20 %.

Der Graph zeigt monatliche Bruttoumsätze mit getrennten Linien für Gesamtumsatz, Abos und PPV Messages. Monats- und Tagesdetails, Datumsfilter, CSV-Export und die Navigation sind bedienbar. Eine weitere HTML-Kopie lässt sich innerhalb der Demo unter **More → Download HTML file** speichern.

Alle Zahlen und Aktionen sind für die interne Präsentation simuliert. Zahlungen und Nachrichten werden nicht an externe Dienste gesendet; Änderungen an der Demo bleiben im lokalen Browserspeicher.

Die Darstellung orientiert sich am bereitgestellten Screenshot bei einer Browser-Inhaltsfläche von 1294 × 724 Pixeln und 100 % Zoom. Roboto-Schrift, Symbole und Daten sind in der HTML-Datei eingebettet.
